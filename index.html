Local Command Line Utility: ios2droid

For batch processing, automated CI/CD builds, or compiling larger Xcode projects, use the included CLI tool located in bin/ios2droid or scripts/converter.py:

./bin/ios2droid analyze AppName.ipa

Inspects Mach-O encryption, architecture, Info.plist metadata, and touchHLE compatibility.

./bin/ios2droid convert AppName.ipa -o AppName_android.apk

Wraps the iOS app with the embedded runtime container into a signed, installable Android APK.

./bin/ios2droid project ./ios_xcode_project -o ./android_project

Translates Xcode structure, Info.plist -> AndroidManifest.xml, Localizable.strings -> strings.xml, and Swift to Kotlin.

How to Add this Repository

  • 1
    Open the F-Droid application on your Android device.
  • 2
    Navigate to Settings > Repositories and tap the + (Add) button.
  • 3
    Scan the QR code above or paste the Repository URL: https://pratech1015.github.io/IOSonDroid/repo
  • 4
    Confirm the repository fingerprint and pull down to sync and install any app.
  • 1
    Open Neo Store or Droid-ify.
  • 2
    Go to Settings > Repositories > Add Custom Repository.
  • 3
    Paste the URL https://pratech1015.github.io/IOSonDroid/repo and tap Save.
  • 1
    In Obtainium, tap Add App.
  • 2
    You can add apps either directly from their official GitHub releases or via this F-Droid repository.
  • 1
    Browse the catalog above and tap Download APK on any desired app.
  • 2
